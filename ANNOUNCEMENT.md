## Platform: Lingua Franca (Mandatory)

This year, there is **no choice of platform**: all teams will implement their solution in **[Lingua Franca (LF)](https://www.lf-lang.org/)**.
LF is a coordination language that provides timing, concurrency, and state-machine modeling (via its **modal models**), while the low-level code is written in C. It is built on top of the Pico SDK and the Pololu 3pi+ 2040 robot library you used in the previous labs, so your lab experience still applies.

AqeddachAuto is a natural fit for LF: it must react to sensors, keep track of time, and switch between well-defined behaviors.

**Before Friday, every team member must:**

1. Make sure all the toolchain are up. 
2. Make sure they can compile an LF program for the RP2040.
3. Build and flash on a robot, so that no time is lost on installation issues during the hackathon.
